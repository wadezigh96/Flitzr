What Flitzr does

A transparent policy-checking layer for finance-related work discussed in Atlassian tools.

⌕

Review proposed spend

Evaluate a proposed amount against explicit demo guardrails instead of guessing missing financial information.

◇

Explain the decision

Return a deterministic result that makes the approval threshold and daily budget impact easy to understand.

⛨

Keep people in control

Flag cases that need human review. Flitzr does not authorize or execute payments.

Simple demo guardrails

The current prototype uses fixed illustrative limits so its decisions are reproducible during evaluation.

$25
Maximum single expense in the demo
$100
Maximum projected daily spend in the demo
These values are hard-coded demonstration limits — not live balances, customer-configured policies, financial advice, or a connection to a bank or wallet.

How the evaluation works

The prototype checks only the values supplied to it. It rejects missing or invalid amounts rather than inventing financial context.

01 · Inputs
Proposed amount + confirmed daily spend
→
02 · Policy check
Validate values and apply demo limits
→
03 · Decision
Allow within demo limits, require review, or block

Built with a clear safety boundary

Flitzr is an evaluation-only prototype built for the Atlassian Forge ecosystem.

No wallet connection

No bank account, wallet, or live balance access.

No transaction execution

No signing, submitting, transferring, or broadcasting funds.

Human approval stays human

A policy result is guidance for review, not payment authorization.

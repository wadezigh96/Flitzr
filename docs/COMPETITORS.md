# Competitive position

Flitzr is not trying to out-volume Bankr or out-distribute MetaMask.

## Category

Defencial-first execution runtime for onchain financial agents on Base.

## Map

| Layer | Who | Flitzr relationship |
|-------|-----|---------------------|
| Chat execution terminals | Bankr, HeyAnon, Griffain, Wayfinder | Bankr is a *rail*. Flitzr sits above it. |
| Agentic wallets | Privy, Dynamic, MetaMask Agent, Coinbase Agents | Privy = user wallet. Dynamic = agent server wallet. |
| Yield agents | Giza ARMA, Almanak, Olas | Different job (AUM / rebalance), not NL plan + approval. |

## Why this wins a 90-second judging slot

Most agent apps optimize for *saying yes to a sentence*.
Flitzr optimizes for *not moving money until Defencial and a signature agree*.

- Deterministic $25 / $100 gates independent of the model
- Preview-first — no silent broadcast
- User funds (Privy) separated from agent wallet (Dynamic)
- One router across Bankr, Definitive Flash, Uniswap
- Public reviewer endpoint: `/api/dynamic/status`

## Do not claim

- That Flitzr replaces Bankr
- That x402 is paid unless HTTP 402 is actually returned
- That the Dynamic address is stable if production has not redeployed the pin commit

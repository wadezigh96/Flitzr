**Target duration:** 2–3 minutes. Record only after the Forge app has been installed and tested on a development Atlassian site.

1. Open a Jira issue describing a proposed operational expense.
2. Open Flitzr Finance Guardian in Rovo.
3. Ask it to evaluate a USD 20 expense with USD 30 already spent today.
4. Show the result: projected daily spend USD 50 and remaining demo budget USD 50.

7. Explain that these are illustrative demo values and that the action only evaluates policy. No wallet is connected, no transaction is signed, and no funds move.
